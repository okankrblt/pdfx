AdMob Requirement for Play Store & App Store

Google requires all publishers to declare their developer website in the app store listings. This website must host a valid app-ads.txt to fight fraud and secure ad earnings.

1. Connecting Your Domain and App Store Listings

To activate your ad revenue and enable AdMob, follow these steps:

  1. Host this Webpage: Deploy these files (index.html, style.css, app.js) on your own web server or a free static host like GitHub Pages, Vercel, Netlify, or Firebase Hosting.
  2. Set Developer URL: In Google Play Console or Apple App Store Connect, update your store listing's "Developer Website" to point to your hosted website domain (e.g. https://yourcompany.com).
  3. Deploy app-ads.txt: Save a raw text file named app-ads.txt in the root of your domain (e.g., https://yourcompany.com/app-ads.txt) containing the AdMob lines provided in the cards above.

2. AdMob App IDs Reference

During Android or iOS application compilation, the AdMob App ID must be added in your app's main metadata descriptors:

Android (AndroidManifest.xml)

<manifest>
    <application>
        <!-- Sample Test ID shown. Replace with your actual AdMob App ID -->
        <meta-data
            android:name="com.google.android.gms.ads.APPLICATION_ID"
            android:value="ca-app-pub-3940256099942544~3347511713"/>
    </application>
</manifest>

iOS (Info.plist)

<key>GADApplicationIdentifier</key>
